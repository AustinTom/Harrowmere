# Harrowmere asset list

Every model, kit, animation set and texture the game needs, in priority order.
The full list is [`data/art/asset_manifest.csv`](../data/art/asset_manifest.csv) (795 rows, about
1,530 files). It is generated by [`tools/art/gen_asset_manifest.py`](../tools/art/gen_asset_manifest.py):
edit the tables there and re-run `python3 tools/art/gen_asset_manifest.py --summary`.

Nothing here removes a placeholder. Every row starts as `status = placeholder`, and the game keeps
drawing its primitive until a `.glb` turns up at the row's `path`. See `docs/art_pipeline.md` for how
models get found.

building kits, weapons, armour, and props last.

## How the count stays this low

**About 1,590 base items come from 405 item model files** (arcane 265 items from 55 files, gear 297
from 79, neutral 446 from 108, shared tools, consumables and components 583 from 163).

1. **One mesh, many items.** An item row is a base mesh. Iron, steel, bronze, Ossuan and other
   variants only swap a swatch in `palette_metal`. Quality tiers and regional styles are the same mesh
   with a different swatch or trim. Data entries point at it with `"model": "<mesh id>"`, and
   `covers_items` says how many base items each mesh is planned to serve.
2. **Enchanting adds no models.** An enchanted or unidentified item is the base mesh plus a glyph
   decal and a glow (`decal_glyphs`, `vfx_magic`).
3. **Modular guns.** Guns are built from 4 barrels, 4 stocks, 4 actions and 3 sights, which matches
   the crafting design where a rifle can take a new barrel or stock later.
4. **One skeleton for every race.** `humanoid_short`, `humanoid_small` and `humanoid_large` are the
   master humanoid skeleton re-proportioned. Clothing and armour are modelled once and fitted with
   shape keys, so every armour piece fits every race without a copy per race.
5. **Residents come from a kit.** Body plus head plus hair plus clothing plus a palette swatch. Six
   races, two sexes, 4 to 6 heads each with shape keys, 16 hair styles, 10 beards and 35 clothing
   pieces give thousands of distinct residents for the 25,000 simulated people.
6. **Palette atlases instead of textures.** Most props, items and clothes UV onto `palette_main`,
   a 256-pixel swatch atlas. Buildings and dungeons use seven shared trim sheets. A whole region can be
   recoloured (lush at high Resonance, sooted at low) by swapping the atlas, not the meshes.
7. **Buildings are kits.** Eight building styles of 24 to 29 snap pieces each (1 m grid, 3 m storeys)
   build every house, shop and factory. The 49 prefabs and 16 city landmarks are assembled from them.
   Dungeons work the same way with nine kits for 250 ruins and 100 caves.
8. **Books share six meshes.** The 1,000 lore books use 6 book meshes and a 60-cover atlas, so they
   are not counted as items.
9. **Creatures share rigs.** 46 creatures and 8 unique bosses on 13 rigs. Warped variants (glassback
   elk, ice bear) are a base animal plus attachments and a swatch.

## Columns in the CSV

| Column | Meaning |
|---|---|
| `id` | Same id as the game data (`items.json`, `actors.json`, area structure `kind`), with no category prefix, as the art pipeline requires. Ids ending `_NN` are groups of variants `_01` to `_<count>` |
| `tier` | 0 to 4, as above |
| `category`, `subcategory` | animations, buildings, characters, creatures, dungeons, items (`pool/family`), nature, props, terrain, textures |
| `kind` | `model`, `prefab` (assembled from a kit), `kit` (a folder of snap pieces), `kit_piece`, `anim_set`, `rig`, `texture`, `decal`, `vfx` |
| `path` | Where the file goes. A `.glb` dropped there replaces the placeholder |
| `binds_to` | What it replaces in the game data |
| `shared_base` | The mesh, kit or race this one derives from |
| `count` | Files this row stands for (kits: number of pieces) |
| `covers_items` | Planned base items that use this mesh |
| `rig` | Skeleton |
| `budget_class`, `tri_budget`, `tex_budget` | Budget class from the art style guide and its triangle and texture budgets (see below) |
| `texture`, `maps` | Which shared texture it uses, and which maps a texture row needs |
| `placeholder` | What the game draws until the model lands |
| `status` | `placeholder` for now. Change it to `wip` or `done` as models land |
| `notes` | Design notes |

## Budgets

Triangle and texture budgets come from the art style guide (`docs/art/README.md`, PR #5), which is
still a draft. Each row gets a `budget_class`, and the generator fills in the numbers, so a change to
the guide is a one-line edit in `BUDGETS`.

| Class | Triangles | Textures | Rows |
|---|---|---|---|
| hero (player, companions) | 15k to 25k | 2 x 2048 | 2 |
| resident | 8k to 12k | shared 2048 set per race and outfit family | 20 |
| resident_part (bodies, heads, clothes, armour) | part of the resident budget | same | 185 |
| creature | 3k to 30k | 1024 to 2048 | 46 |
| boss | up to 50k | 2 x 2048 | 8 |
| held_item (weapons, shields, foci) | 1.5k to 4k | 1024 or family atlas | 103 |
| small_prop | 200 to 2k | shared atlas | 201 |
| medium_large_prop | 2k to 20k | shared atlas, trim sheets | 88 |
| building_kit_piece | 0.5k to 5k per piece | trim sheets | 17 kits |
| house | 20k to 60k | trim sheets | 36 |
| landmark | 100k to 250k | trim sheets plus a unique 2048 | 16 |

The guide also sets three rules, which the CSV notes carry. Every plant needs a healthy and a dead
variant for Resonance. Faction-owned parts (banners, uniforms, lamps, signs) are swappable `owner_*`
slots, not one model per faction. An item's held, dropped and inventory-icon versions are one asset.

## What the art pipeline needs to support this

These are points for `docs/art_pipeline.md`. None of them block tier 0.

- **Item meshes shared by id.** Most items will name a mesh with `"model": "longsword"`, which the
  pipeline already supports.
- **Random variant picks** for grouped structure ids (`townhouse_terrace_01` to `_06`,
  `grass_clumps_01` to `_04`), the same way `race_defaults` works for residents.
- **Terrain materials** for ground. Today the ground is a flat tint in `World._build_ground()`.
- **Runtime assembly of residents** from kit parts (body, head, hair, outfit, swatches). Until then,
  the prebuilt `<race>_a` to `<race>_h` variants in tier 2 cover it.
- **Shape-key fitting** of clothing and armour to the short, small and large bodies.

## Assumptions to check

- `scav_brute` has no race in `actors.json`. The list makes it a heavy human so that it stays on the
  tier 0 rig. It can become an orc once `humanoid_large` exists.
- Creature, boss, landmark and companion ids are proposals. The world generation and quest threads
  will set the real ones, and the generator is the place to rename them.
- The item total is about 1,590 against the target of about 1,500. That leaves room to cut whatever
  the item and crafting threads don't use.
